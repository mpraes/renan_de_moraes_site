Over the last two years, I had the great opportunity to work as a Senior Technical Consultant delivering Data Engineering and Architecture solutions.

### Key Consulting Highlights:

1. **Python/Pandas & MSSQL Vehicle Tracking Pipeline**:
- Built Python pipelines running inside Azure VMs consuming REST APIs for vehicle fleet tracking.
- Designed a Star Schema (1 Fact, 5 Dimensions) in SQL Server.
- Automated scheduling via Jenkins with e-mail alert notifications.

2. **RPA with Python & SAP RFC for MRP Stock Automation**:
- Automated complex inventory MRP reporting for a global multinational.
- Extracted SAP table data via RFC, transformed with Pandas, and staged in SQL Server.
- Automated Excel report generation delivered to buyers weekly.

3. **High-Complexity SQL Queries on Oracle Database**:
- Developed advanced SQL queries (CTEs, Window Functions) on Oracle DB to feed enterprise BI dashboards.

4. **Data Warehouse Migration from VM/SSIS to Microsoft Fabric**:
- Architected the transition from legacy SQL Server VM / SSIS setups to Microsoft Fabric Lakehouse (Bronze, Silver, Gold).
- Migrated 50+ Power BI reports to Spark SQL and Direct Lake semantic models.
