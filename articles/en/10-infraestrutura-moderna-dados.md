An overview of the Modern Data Stack (MDS): cloud storage, orchestration, security, and observability tools.

### Core Architecture Components:
- **Storage & Compute**: Azure Data Lake Storage, AWS S3, Snowflake, Databricks.
- **Orchestration**: Apache Airflow, Dagster, Prefect, Jenkins.
- **Observability & Data Quality**: Great Expectations, Elementary, Prometheus.
