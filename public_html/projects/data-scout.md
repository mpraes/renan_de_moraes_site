# Data Scout (⭐ 5 Stars on GitHub)

*Repository*: [https://github.com/mpraes/data_scout](https://github.com/mpraes/data_scout)  
*Category*: Applied AI & Automated Analytics  
*Language*: Python  

## Overview
**Data Scout** is a "one-click" data diagnostic tool that ingests raw datasets, runs automated data cleaning, computes key statistical metrics/KPIs, and leverages LLM synthesis to turn raw metrics into concise executive business narratives.

## Features
- One-click dataset profiling and null/outlier cleaning.
- Automatic calculation of summary metrics and correlations.
- LLM-generated executive narratives translating cold numbers into business insights.
