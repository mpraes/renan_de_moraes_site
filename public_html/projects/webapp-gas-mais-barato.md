# WebApp Gás Mais Barato (⭐ 6 Stars on GitHub)

*Repository*: [https://github.com/mpraes/webapp_gas_mais_barato](https://github.com/mpraes/webapp_gas_mais_barato)  
*Category*: Full Stack Web Application  
*Language*: TypeScript / Web Stack  

## Overview
A lightweight web application designed to help consumers locate and compare cooking gas prices in their region, reducing household energy expenses.

## Features
- Real-time price aggregation and store listing.
- Responsive mobile-first interface.
- Instant search and distance filtering.
