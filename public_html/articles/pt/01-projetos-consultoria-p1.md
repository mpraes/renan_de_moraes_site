Nos últimos dois anos surgiu uma oportunidade muito interessante de trabalhar como Pessoa Jurídica prestando serviços de consultoria técnica em Engenharia de Dados e Arquitetura.

### Destaques dos Projetos de Consultoria:

1. **ETL em Python/Pandas & MSSQL para Rastreamento Veicular**:
- Desenvolvimento de pipeline Python rodando dentro de uma VM Azure para consumo de API REST de rastreamento veicular.
- Modelagem Star Schema (1 Fato e 5 Dimensões) persistida em SQL Server.
- Orquestração agendada via Jenkins com alertas automáticos por e-mail em caso de falha.

2. **RPA com Python & SAP RFC para Atualização de Estoque MRP**:
- Automação de extração e tratamento de relatórios complexos de estoque em multinacional.
- Leitura de tabelas SAP via RFC e transformações em Pandas com Staging no SQL Server.
- Geração automática de relatórios Excel postados em filas e distribuídos para compradores.

3. **Queries SQL de Alta Complexidade no Banco Oracle**:
- Desenvolvimento de consultas avançadas (CTEs, Window Functions) diretamente no banco Oracle de produção para alimentar relatórios corporativos.

4. **Migração de Data Warehouse VM/SSIS para Microsoft Fabric**:
- Arquitetura e transição de réplicas SQL Server para Microsoft Fabric Lakehouse (Camadas Bronze, Prata e Ouro).
- Migração de mais de 50 relatórios Power BI utilizando Spark SQL e modelos semânticos.
