In Part 2 of my consulting retrospective, I highlight projects focused on enterprise data culture, Databricks CI/CD workflows, and applied AI agents.

### Key Deliverables & Insights:

1. **BI & PySpark Refactoring in Azure Databricks**:
- Worked with large-scale telemetry data optimizing PySpark notebooks in Azure Databricks.
- Implemented Kimball dimensional modeling consuming Silver layer Delta tables.
- Standardized CI/CD deployment pipelines using Git repositories and cluster automation.

2. **Applied AI & LangGraph Support Automation**:
- Built multi-agent AI systems using LangGraph with long-term memory for N1 support automation.
- Integrated Databricks OAuth, Redis ElastiCache, and Prometheus observability.

3. **Core Lessons Learned**:
- Rapid adaptation across diverse cloud ecosystems (Azure, AWS, SAP).
- Focus on clean code, modular design, and robust automated validation before production.
