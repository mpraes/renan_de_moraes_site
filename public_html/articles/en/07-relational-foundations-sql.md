A hands-on guide covering core relational SQL foundations: primary keys (PK), foreign keys (FK), constraints, and table joins.

### Key Topics Covered:
- UNIQUE, NOT NULL, and CHECK constraints.
- Practical differences between INNER JOIN, LEFT JOIN, and FULL OUTER JOIN.
- Enforcing referential integrity to prevent orphan records.
