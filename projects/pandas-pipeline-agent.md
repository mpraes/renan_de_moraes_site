## Overview
An intelligent, automated system for generating and testing Pandas data cleaning and transformation pipelines using AI agents and structured quality checklists.

## Key Features
- **AI Agent Orchestration**: Uses LLM agents to automatically analyze raw messy datasets and generate clean Python transformations.
- **Automated Quality Checklists**: Evaluates null values, data type mismatches, and outlier anomalies.
- **Self-Healing Code Execution**: Tests generated Pandas code and automatically corrects transformation errors.

## Tech Stack
- Python
- Pandas
- LLM Agents / LangChain / LangGraph
- Pytest Data Validation
