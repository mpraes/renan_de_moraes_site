## Overview
**Can I Code Without AI?** is a sleek, interactive web application built to challenge developers on their reliance on AI coding assistants (GitHub Copilot, ChatGPT, Claude, Cursor). It presents developers with interactive challenges and self-assessment metrics to test core programming foundations without generative AI prompts.

## Key Features
- **Interactive Self-Assessment**: Evaluates developer proficiency in core algorithms, data structures, and syntax without AI assistance.
- **Bilingual Interface**: Native support for English and Portuguese (`?lang=en` / `?lang=pt`).
- **Developer Insights & Scorecard**: Generates shareable developer diagnostic badges highlighting strengths and areas for foundational review.
- **Sleek Dark Theme UI**: Built with modern web standards, responsive design, and smooth user interactions.
