# Single Node Data Warehouse (⭐ 5 Stars on GitHub)

*Repository*: [https://github.com/mpraes/single_node_dw](https://github.com/mpraes/single_node_dw)  
*Category*: Data Engineering Framework  
*Language*: Python  

## Overview
A lightweight single-node Data Warehouse ETL framework designed for fast, modular ELT/ETL pipelines without requiring heavy distributed cluster management.

## Features
- Plug-and-play source and target connectors (PostgreSQL, SQL Server, Oracle, CSV, DuckDB).
- Modular ETL pipeline execution with built-in logging and transaction safety.
- Ideal for small-to-medium enterprise data warehouses and single-server deployments.
