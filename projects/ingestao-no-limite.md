*Language*: Python  

## Overview
**Ingestão no Limite (Edição Hardware Leve)** is a popular open-source benchmark proving that true data engineering relies on optimized code, memory mapping, and streaming logic rather than expensive cloud compute power.

## Key Features & Results
- **~70 Million Record Processing**: Ingests and processes 70 million records on lightweight, low-cost local hardware.
- **Memory-Constrained Engineering**: Implements streaming generators, chunked batching, and DuckDB vectorized processing.
- **Zero Heavy Infrastructure**: Demonstrates that proper database indexing and streaming eliminates the need for expensive cluster provisioning.

## Tech Stack
- Python
- DuckDB / Polars
- SQLite
- Memory Mapping & Streaming Generators
